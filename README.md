# CivBench

CivBench 是一个以城市长期发展为背景的 AI 综合能力评测项目。模型需要在连续的模拟年份中完成代码、科研与工程任务，并将通过验收的成果用于城市建设和运行，承担预算、资源、工期和后续维护的影响。

本仓库仅提供项目介绍。全部实现、题目、数据、设计文档、测试和历史开发资料统一保存在 [CivBench-Dev](https://github.com/Alpaca233114514/CivBench-Dev)；该开发仓库当前为私有仓库，访问需要授权。

## 评测方式

- **长期决策**：支持 30、60、100 年三个档位，默认 60 年；开局锁定年限，逐年观察、决策和结算。
- **渐进披露**：模型通过 CLI 获取当前简报和按需查询的信息，未来事件、隐藏测试和参考答案不进入正常作答流程。
- **真实代码交付**：在独立项目仓库中实现题目，经历首交付、适应和维护三个阶段，由控制器冻结版本并独立验收。
- **成果用于城市**：符合条件的冻结代码可生成城市运行提案，实际采用后承担对应的行动、资金、资源与工期。
- **可追溯交卷**：保留逐年决策、项目验收、评分和导出记录；历史批次沿用原版本，不随新规则重评分。

## 任务范围

项目包含能源、电力、交通、水务、财政、科学计算、工程优化、医学和金融等领域，接入 BigCodeBench、SciCode-Verified、MiniZinc 与 PGLib-OPF 等外部任务或算例。各类材料的来源、版本和许可证在开发仓库中分别保留，以具体任务契约和验收结果为准。

当前开发版本为 **0.2.16-dev**，科技树共 52 个节点。科技解锁要求原题通过独立验收，同时满足前置条件、资金和年度机会限制；当前每年只能尝试一次。科技分占总分 12%，达标数为 `min(52, 锁定总年限)`，全树覆盖率另列。

## 结果边界

CivBench 当前属于未校准的合成城市 Dev/Beta 评测。程序测试通过、原题验收、提案可行、城市实际采用和模拟收益是不同层次的证据，需要分别报告。

现有结果不构成真实城市、临床、金融或工程能力认证，也不构成正式模型排名；综合能力字段 `capability_score` 仍保留为 `null`。同用户全盘可读的本地试跑不能宣称为正式防泄漏评测。
